# MAW MCP tool reference

Server `maw-coordination` (exposed to agents as `maw`). 39 tools. Generated by `maw tools --markdown`.

## `maw_goal_get`

Get the project's current goal, status, milestone and focus.

- **Roles:** any role
- **Read-only:** true

```json
{
  "type": "object"
}
```

## `maw_goal_create`

Leader: create the project's goal when none is active (fails while one is). Only the user can change or cancel an existing goal.

- **Roles:** leader
- **Read-only:** false

```json
{
  "properties": {
    "objective": {
      "description": "What the team should achieve.",
      "type": "string"
    },
    "success_criteria": {
      "default": [],
      "description": "How to tell it is done: concrete, checkable statements.",
      "items": {
        "type": "string"
      },
      "type": "array"
    }
  },
  "required": [
    "objective"
  ],
  "type": "object"
}
```

## `maw_workspace_propose`

Leader: propose a different working folder for the project (WSL or Windows path), for instance a dedicated folder instead of a home folder. Nothing changes until the user approves it; every agent is then restarted in the new folder. Not possible while tasks are assigned, running, blocked or waiting for review.

- **Roles:** leader
- **Read-only:** false

```json
{
  "properties": {
    "path": {
      "description": "The folder the project should live in: a WSL path (`/home/me/projects/app`, `~/projects/app`) or a Windows path (`C:\\Users\\me\\projects\\app`). Created if it does not exist.",
      "type": "string"
    },
    "reason": {
      "description": "Why this folder fits the project (shown to the user).",
      "type": "string"
    }
  },
  "required": [
    "path",
    "reason"
  ],
  "type": "object"
}
```
